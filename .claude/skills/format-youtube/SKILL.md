# Format — YouTube video script

A script for a short demo/walkthrough video (usually 2–6 min). The output is the
spoken script + on-screen cues, not a blog post. Show the thing working.

## Structure
- **Title + one-line premise** — what the viewer will be able to do by the end.
- **Hook (0:00–0:15)** — the problem or the "watch this", said out loud. No slow intro.
- **Body — demo beats.** Break into short sections, each a concrete step done on
  screen. Write what's said AND what's shown:
  - `[SCREEN: ...]` for what's on screen (the UI, the code, the terminal).
  - Spoken lines in plain sentences, contractions, second person ("you").
- **Show real product** — the actual Windmill UI/CLI, real code, a real run. A working
  demo beats explanation.
- **Outro (last 15s)** — recap the payoff in one sentence + a clear next step
  (docs link, "try it", subscribe). Keep it short.

## Register
Conversational and tight — it's spoken, so short sentences, no jargon dumps, no
reading a spec aloud. Technically credible. Never fabricate a capability or a
number; if you'd demo something, it has to be real.
